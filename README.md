# Machine Learning Training Projects

This repository contains various machine learning projects focused on classification and regression problems.

## Projects

### 1. Credit Card Fraud Detection (Classification)
- **File**: `Classification_Model.ipynb`
- **Description**: A machine learning model to detect fraudulent credit card transactions
- **Features**:
  - Transaction details (date, time, amount)
  - Merchant information
  - Location data (latitude, longitude)
  - Customer information
- **Target Variable**: `is_fraud` (binary classification)

### 2. Housing Price Prediction (Regression)
- **File**: `Housing_Price_Prediction.ipynb`
- **Description**: Predicting house prices using various features
- **Features**:
  - Property characteristics (bedrooms, bathrooms, square footage)
  - Location information
  - Building grade
  - Year built and renovated
- **Target Variable**: `price`

## Getting Started
To run these notebooks:
1. Ensure you have Python installed
2. Install required libraries: `pip install numpy pandas matplotlib scikit-learn seaborn`
3. Open the notebooks using Jupyter Notebook or JupyterLab or Google Colab
4. Run the cells sequentially to reproduce the analysis
